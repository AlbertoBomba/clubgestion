🏆 Calendario de Partidos

Widget de integración para webs de escuelas deportivas

📋 Instrucciones de uso

Para integrar este widget en tu web, copia y pega este código HTML:

<!-- 1. Configurar URL del portal (IMPORTANTE) -->
<script>
    window.CLUB_PORTAL_API_URL = 'https://https://vaed.es';
</script>

<!-- 2. Contenedor del widget -->
<div id="club-matches" 
     data-limit="10"
     data-show-team-filter="true"
     data-show-logo="true">
</div>

<!-- 3. Script del widget -->
<script src="https://vaed.es/widget/matches.js"></script>

⚠️ Importante: Reemplaza https://vaed.es con la URL real de tu servidor portal donde está alojada la API de Laravel.
